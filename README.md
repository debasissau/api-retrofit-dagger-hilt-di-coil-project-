## 🚀 Tech Stack

* Kotlin
* MVVM Architecture
* Retrofit (API calls)
* Dagger Hilt (Dependency Injection)
* Coil (Image Loading)
* Jetpack Compose / XML

---

## 📂 Architecture

This project follows **MVVM (Model-View-ViewModel)** architecture.

* UI → ViewModel → Repository → API

---

## 🔧 Features

* Fetch data from API using Retrofit
* Dependency Injection using Hilt
* Image loading using Coil
* Clean architecture and scalable code
